# Workspace files

`FileExplorer.tsx` browses the selected workspace's files through the files API, lazily loading directory children. `FileContentPane.tsx` previews files opened from the explorer beside the conversation: one open-file tab strip, read-only content, and per-file loading/error states cached per workspace. Markdown files (`.md`, `.markdown`) render through the shared conversation `Markdown` component with frontmatter support; a header toggle switches between rendered and raw text views. File content is never edited here. The pane also hosts the app's browser tab; see [browser](/src/features/browser/README.md).

`App.tsx` owns the pane share because it sizes the workspace grid's second column via `--file-pane-share`. The share is dragged on the pane's left separator (pointer or keyboard, mirroring the sidebar handles), persists in `pi-livecraft.file-pane-share`, and stays between 25% and 75% (`file-pane-width.ts`). The pane keeps a 280 px CSS minimum; above that minimum it grows and shrinks with the workspace, so sidebar changes preserve the chosen proportion. Below 900 px the pane and separator hide. Share bounds are covered by `test/file-pane-width.test.ts`.
